技术支持

本页可用作 App Store Connect「技术支持 URL」。无需登录账号即可使用本应用。

联系我们

邮箱： support@nightelf.app

请尽量说明：设备型号、iOS 版本、App 版本号（「我的 → 关于我们」），以及问题复现步骤。

常见问题

需要注册账号吗？

不需要。数据默认保存在手机本地。

如何备份 / 换机？

打开「我的 → 设置与隐私 → 导出本地数据」，将 JSON 自行保存。 新设备安装后使用「从剪贴板导入」。注意：导入会全量覆盖本机现有数据。

购买了 Pro 但没有生效？

  1. 确认使用购买时的同一个 Apple ID；
  2. 在应用内点击「恢复购买」；
  3. 检查网络后重试；仍失败请邮件联系并附上大致购买时间。

如何取消订阅？

在 iPhone：设置 → Apple ID → 订阅，找到「八戒」相关订阅进行取消。 取消后当前已付周期通常仍可使用至周期结束（以 Apple 显示为准）。

为什么有广告？如何去掉？

免费版可能显示开屏广告与激励广告。升级 Pro（月度 / 年度 / 终身）后去除广告，并提高习惯等权益上限。

激励广告看完了但没有加习惯名额？

需完整观看并获得奖励回调后才会 +1 名额；中途关闭可能无效。免费版通过广告增加的名额有上限，用尽后请升级 Pro。

本应用能治疗成瘾吗？

不能。本应用是自助行为管理工具，不诊断、不治疗。如有需要请寻求专业帮助。

通知一直弹？

仅在您开启「每日练习提醒」后才会本地通知。可在应用设置关闭，或在系统设置中关闭本应用通知权限。
