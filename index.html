法律与支持

「八戒」是自助行为管理工具（wellness），不提供医疗诊断或成瘾治疗。 下列页面可填入 App Store Connect 的隐私政策 URL、许可协议 / EULA、技术支持 URL。

发布到 GitHub Pages 后，将下列链接填入 ASC。首次启用请见 PAGES.md。

文档入口

  • 隐私政策

    数据如何保存在本机、广告、内购与第三方 SDK 说明。

  • 用户协议（服务条款）

    使用规则、Pro 订阅与终身购买、免责声明与责任限制。

  • 技术支持 / 联系我们

    无账号说明、常见问题与联系邮箱（ASC「技术支持 URL」）。

上架填写对照

  • 隐私政策 URL → …/privacy.html
  • 技术支持 URL → …/support.html
  • 营销 URL（可选）→ 本页 …/ 或 …/index.html
  • 自定义 EULA（可选）→ …/terms.html；也可使用 Apple 标准许可协议
