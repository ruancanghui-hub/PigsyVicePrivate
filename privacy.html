隐私政策

生效 / 更新日期：2026-09-16
适用产品：iOS 应用「八戒-戒掉坏习惯」（Bundle ID：com.nightelf.bajie）

欢迎使用「八戒」（下称「本应用」）。本应用由 Nightelf / 八戒团队（下称「我们」）提供， 帮助您以自助方式记录与减少不想要的行为。 本应用不提供医疗诊断、成瘾治疗或任何专业医疗服务，不能替代医生或专业机构的意见。

请您在使用前仔细阅读本政策。继续使用即表示您理解我们如何处理相关信息。

1. 我们收集哪些信息

1.1 默认保存在您设备上的内容

本应用不要求注册账号。下列内容默认仅保存在您的设备本地（如 SQLite / 系统偏好）：

  • 戒除习惯名称、目标周期与额度；
  • 破戒记录、可选原因标签与备注；
  • 积分流水、礼物、练习与冲动引导完成记录；
  • 主观「感受进度」（清晰度 / 稳定性自评，非健康监测）；
  • 外观偏好、提醒开关与时间；
  • Pro 权益开关、通过激励广告获得的习惯名额等权益状态。

我们不会将上述核心内容主动上传到自有服务器（当前版本无强制云同步、无自有用户账号体系）。

1.2 您主动导出的数据

您可使用「导出本地数据」生成 JSON 备份并复制到剪贴板或自行保存。 导出后文件的去向由您控制；导入为全量覆盖，请谨慎操作。

1.3 我们不主动收集的信息

  • 姓名、电话、邮件等联系方式（除非您主动发邮件联系我们）；
  • 精确位置、通讯录、相册、麦克风、健康/运动传感器数据；
  • 医疗记录或临床诊断信息。

2. 权限

  • 通知：仅当您在设置中开启「每日练习提醒」时请求。 您可随时在系统设置中关闭；拒绝不影响核心记录功能。
  • 健康 / 定位 / 麦克风 / 相册：当前版本不申请。

3. App 内购买

Pro 会员（月度订阅、年度订阅、终身非消耗型）通过 Apple App Store / StoreKit 完成支付。 交易与收据由 Apple 处理，适用 Apple 隐私政策。 我们仅在您的设备上保存是否已解锁 Pro 的状态，用于功能开关（多习惯、完整练习、无限礼物、去除广告等）。

4. 广告

免费版可能展示 Google AdMob 提供的开屏广告与激励广告 （例如观看完整激励广告以增加习惯名额）。解锁 Pro 后，本应用将不再展示上述广告。

AdMob 可能根据其政策处理设备标识符、广告交互等数据，详情见 Google 隐私政策 与 AdMob 帮助。 当前版本未强制弹出「App 跟踪透明度（ATT）」授权弹窗；若后续变更，我们将更新本政策并在系统要求时征得同意。

5. 分析与崩溃（可选配置）

工程可能包含 Firebase Analytics / Crashlytics / Remote Config 等依赖。 仅在实际完成 Firebase 初始化并启用时，才可能收集匿名化的使用或诊断数据。 若未配置或未启用，则不会因此向 Firebase 上传数据。启用时适用 Firebase 隐私说明。

6. 信息如何使用

本地数据仅用于向您提供应用功能，例如：

  • 记录习惯与结算「守住 / 破戒」状态；
  • 积分、礼物与练习进度；
  • 本地提醒；
  • 根据 Pro / 广告权益控制功能与广告展示。

我们不会出售您的本地内容。因无自有账号云端库，我们也无法在服务器侧「查看」您的习惯明细。

7. 信息共享

除下列情形外，我们不向第三方共享您的本地内容：

  • Apple（内购结算）；
  • Google AdMob（广告展示与相关广告技术，限免费版场景）；
  • 在您主动导出备份后，由您自行分享的文件；
  • 法律法规要求或为保护用户与公众安全所必需。

8. 数据保留与删除

  • 本地数据随应用保留；卸载应用通常会删除本机相关数据（以 iOS 系统行为为准）。
  • 删除前建议先「导出本地数据」自行备份。
  • 因无账号，不存在「注销云端账号」流程；停止使用并卸载即可停止本地处理。

9. 儿童与未成年人

本应用面向有自我管理需求的用户，不以儿童为主要服务对象。 若您是监护人并认为未成年人在未经同意的情况下使用了本应用，请联系我们，我们将在合理范围内协助说明处理方式。

10. 安全

数据默认存于您的设备。请妥善保管设备解锁方式，并谨慎对待导出的 JSON 备份（可能包含您自行填写的习惯名与备注）。

11. 政策更新

我们可能适时更新本政策。重大变更将通过更新本页面的「更新日期」并在合理范围内提示。 继续使用即视为了解更新后的政策。

12. 联系我们

隐私相关问题请发送邮件至： ruancanghui@163.com （若您已更换实际上架邮箱，请以 App 内「关于我们 / 支持」或商店页展示为准）。
